5필드 Cron 실행 시각 계산

예약 작업이 한국 시각인지 UTC인지 헷갈릴 때 실제 다음 실행 시각을 확인하세요.

실제 비밀번호·JWT 액세스 토큰·고객 개인정보는 붙여 넣지 마세요.

가상 예제로 직접 사용해 보세요

예약 작업·시간대

파일 업로드·쿠키·분석 추적·외부 스크립트 없음. 입력은 브라우저 메모리에서만 처리합니다.

결과

LOCAL

준비됐습니다. 테스트 데이터를 입력하세요.


  

 

 

  
어떤 문제를 해결하나요?
UTC와 로컬 시간대를 혼동하면 상품 가격 동기화나 백업 작업이 잘못된 시간에 실행됩니다. 표준 5필드 cron을 계산해 실제 앞으로의 날짜 5개를 보여주고, 일자·요일 동시 지정의 규칙도 설명합니다.

  
사용 방법
분, 시, 일, 월, 요일 순서로 5필드를 입력합니다. 예: 0 9 * * 1은 월요일 9시, */15 9-17 * * 1-5는 평일 근무 시간대 15분 간격입니다. 서버가 UTC 기준이라면 UTC를 선택해야 합니다.

  
지원 범위와 주의사항
표준 숫자 Unix cron의 *, 간격, 쉼표 목록, 범위를 지원합니다. Quartz 초 단위 필드나 AWS EventBridge 표현식은 지원하지 않습니다. 실행 가능 날짜만 계산할 뿐 서버가 실제 실행된다고 보장하지 않습니다.

 

 
자주 묻는 질문
AWS EventBridge와 Quartz도 지원하나요?
아니요. 필드 개수·요일 규칙이 달라 표준 5필드 Unix crontab으로 제한했습니다.
일자와 요일을 함께 지정하면요?
일반적인 Vixie crontab처럼 둘 중 하나만 맞아도 실행 후보로 판단합니다. 플랫폼별 규칙을 확인하세요.
다음 실행 시각이 실제 실행을 보장하나요?
아니요. 서버 정지·워크플로 비활성화·일광절약시간 설정으로 실제 실행 여부는 달라집니다.
