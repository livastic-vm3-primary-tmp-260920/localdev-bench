Unix 타임스탬프 변환

로그와 API에서 나온 10자리 초·13자리 밀리초 시각을 한국 시간과 UTC로 확인합니다.

실제 비밀번호·JWT 액세스 토큰·고객 개인정보는 붙여 넣지 마세요.

가상 예제로 직접 사용해 보세요

Epoch·API 디버깅

파일 업로드·쿠키·분석 추적·외부 스크립트 없음. 입력은 브라우저 메모리에서만 처리합니다.

결과

LOCAL

준비됐습니다. 테스트 데이터를 입력하세요.


  

 

 

  
어떤 문제를 해결하나요?
Python 서버의 Unix 초와 JavaScript Date의 밀리초를 혼동하면 날짜가 수십 년 차이 날 수 있습니다. 입력 단위, ISO UTC, 초·밀리초 정수값과 한국·선택 시간대를 한 번에 보여줍니다.

  
사용 방법
타임스탬프 정수와 단위를 입력하거나 Z·+09:00 등이 붙은 ISO 시각을 입력합니다. 자동 단위 판별은 크기로 추정하므로 예전 날짜나 특이한 값에는 초/밀리초 단위를 직접 지정하세요.

  
지원 범위와 주의사항
브라우저 Date가 지원하는 범위를 벗어난 값은 거부합니다. 기기 시계나 서버의 시간대 설정이 잘못된 경우 실제 이벤트 시간을 뜻하지 않을 수 있으므로 원본 로그와 비교하세요.

 

 
자주 묻는 질문
10자리와 13자리 타임스탬프 차이는 뭔가요?
일반적으로 현재 시점의 10자리는 초, 13자리는 밀리초이지만 확정 규칙은 아닙니다. 확실한 단위를 직접 선택하세요.
UTC와 한국시간을 동시에 보여주나요?
예. 하나의 절대 시각을 UTC와 Asia/Seoul, 선택한 기기 시간대로 각각 변환합니다.
시간대가 없는 ISO 날짜를 입력할 수 있나요?
혼동을 막기 위해 Z 또는 +09:00처럼 명시적인 오프셋이 있어야 변환합니다.
