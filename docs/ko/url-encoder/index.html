UTM 링크나 API 요청의 % 인코딩과 쿼리 파라미터를 실제 접속 없이 분석하세요.

실제 비밀번호·JWT 액세스 토큰·고객 개인정보는 붙여 넣지 마세요.

어떤 문제를 해결하나요?
공백이나 %기호, 이중 인코딩으로 webhook 및 광고 캠페인 URL이 깨질 수 있습니다. 쿼리 값 인코딩, +/% 디코딩, 중복 키를 포함한 URL 세부 항목을 표시합니다.

  
사용 방법
한 개의 쿼리 값은 인코딩, 퍼센트 값은 디코딩, 완전한 https URL은 분석을 선택합니다. 도메인·경로·fragment·UTM 등 모든 파라미터를 순서대로 볼 수 있습니다.

  
지원 범위와 주의사항
URL은 문자열로만 해석하고 접속이나 리디렉션을 수행하지 않습니다. URL에 개인 정보·비밀 토큰이 포함돼 있다면 복사해 공유하지 마세요.

 

 
자주 묻는 질문
encodeURI와 encodeURIComponent 차이는 뭔가요?
쿼리 값 인코딩은 &, =, ? 등 구분 문자를 이스케이프하므로 개별 파라미터에 적합합니다.
검사하면 해당 사이트에 접속하나요?
아니요. 외부 호스트에 요청하지 않고 브라우저 안에서 문자열만 분석합니다.
중복된 UTM 파라미터도 보이나요?
예. 반복된 같은 이름의 쿼리 키를 순서 그대로 보여줍니다.
