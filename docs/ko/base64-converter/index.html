Base64 인코딩·디코딩

한글·이모지 등의 문자가 깨지지 않도록 UTF-8을 사용한 Base64 변환을 합니다.

실제 비밀번호·JWT 액세스 토큰·고객 개인정보는 붙여 넣지 마세요.

가상 예제로 직접 사용해 보세요

UTF-8 인코딩

파일 업로드·쿠키·분석 추적·외부 스크립트 없음. 입력은 브라우저 메모리에서만 처리합니다.

결과

LOCAL

준비됐습니다. 테스트 데이터를 입력하세요.


  

 

 

  
어떤 문제를 해결하나요?
Base64는 문자가 아니라 바이트를 처리하므로 단순 btoa/atob는 한글에서 오류가 날 수 있습니다. 텍스트를 UTF-8로 인코딩하고 패딩과 잘못된 UTF-8 복원 오류를 명확히 구분합니다.

  
사용 방법
인코딩 또는 디코딩을 고른 후 가상 텍스트를 입력하고 실행하면 됩니다. 결과는 테스트 API 요청에 복사할 수 있습니다. 단, Base64는 암호화가 아닙니다.

  
지원 범위와 주의사항
텍스트 전용입니다. 이미지·압축파일 등의 바이너리 데이터를 무리하게 텍스트로 해독하지 않습니다. 서버 전송이 없지만 비밀번호를 공유 URL에 넣지 마세요.

 

 
자주 묻는 질문
한글과 이모지도 되나요?
예. Unicode 텍스트를 UTF-8 바이트로 바꾼 뒤 Base64 인코딩합니다.
Base64면 비밀번호가 안전한가요?
아니요. 누구나 디코딩할 수 있습니다. 비밀 데이터는 별도의 암호화가 필요합니다.
이미지나 압축파일도 되나요?
이 기능은 UTF-8 텍스트 전용이며 바이너리 파일 해독은 지원하지 않습니다.
