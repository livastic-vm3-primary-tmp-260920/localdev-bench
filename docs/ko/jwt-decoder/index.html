JWT 헤더·페이로드 분석

JWT 안의 JSON 필드를 이해하기 위한 로컬 분석 도구입니다. 실제 인증 성공 여부는 확인하지 않습니다.

실제 비밀번호·JWT 액세스 토큰·고객 개인정보는 붙여 넣지 마세요.

가상 예제로 직접 사용해 보세요

토큰 구조 분석

파일 업로드·쿠키·분석 추적·외부 스크립트 없음. 입력은 브라우저 메모리에서만 처리합니다.

LOCAL

준비됐습니다. 테스트 데이터를 입력하세요.


  

 

 

  
어떤 문제를 해결하나요?
개발자는 alg, typ, sub, iss, exp와 nbf 같은 필드를 살펴볼 때가 많습니다. 하지만 토큰 내용이 디코딩된다고 서명이 올바르거나 접근 권한이 확인된 것은 아닙니다.

  
사용 방법
가상 예제를 사용하거나 폐기 가능한 테스트 JWT 세 조각을 입력하세요. 헤더·페이로드를 base64url에서 JSON으로 읽고 만료·사용 시작 클레임을 기기 시계와 비교합니다. 서명은 검사하지 않습니다.

  
지원 범위와 주의사항
실제 액세스 토큰, 갱신 토큰 또는 타인 인증 정보를 웹사이트에 붙여 넣지 마세요. 이 서비스는 서버 요청이 없지만 JWT의 클레임 내용은 검증되지 않은 값으로 취급해야 합니다.

 

 
자주 묻는 질문
디코딩되면 유효한 JWT인가요?
아니요. alg 서명, 발급자, 대상, 권한 또는 폐기 여부를 전혀 검증하지 않습니다.
OpenAI나 Shopify 계정에 접속하나요?
아니요. 어떤 토큰도 API 호출에 사용하지 않습니다. 가상 테스트 값만 사용하세요.
exp가 지나면 반드시 로그아웃되나요?
보장되지 않습니다. exp는 검증되지 않은 데이터이고 서버는 해당 시각 이전에도 토큰을 거부할 수 있습니다.
