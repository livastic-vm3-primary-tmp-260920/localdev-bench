어떤 문제를 해결하나요?
각 줄은 정상 JSON인데 파일 전체를 하나의 JSON 객체로 처리해 실패하는 경우가 있습니다. JSONL은 비어 있지 않은 줄마다 완전한 JSON 값이어야 합니다. 잘못된 쉼표·따옴표 등의 줄 번호를 찾아줍니다.

  
사용 방법
가상의 JSONL 텍스트를 붙여 넣고 검사하면 오류 줄 번호, 정상 레코드 수와 자료형이 표시됩니다. 모든 줄이 정상일 때만 JSON 배열로 내보낼 수 있습니다. 표 형태 CSV로 변환하려면 별도 LocalCSV Lab 도구를 활용하세요.

  
지원 범위와 주의사항
JSON 구문만 검사합니다. OpenAI Batch API 요청 구조나 n8n 노드 규격, 업무용 필드 정확성을 확인하는 기능은 아닙니다. 데이터는 서버에 업로드하지 않습니다.

 

 
자주 묻는 질문
JSONL과 JSON 배열의 차이는 뭔가요?
JSONL은 한 줄에 완전한 JSON 값이 하나씩 있습니다. JSON 배열은 대괄호 안에 쉼표로 구분된 값들이 들어 있습니다.
OpenAI Batch API 요청도 검증하나요?
줄별 JSON 구문만 검사하며 API 요청 형식이나 모델·권한은 검증하지 않습니다.
원본 NDJSON 파일을 업로드하나요?
아니요. 입력한 텍스트를 내 브라우저에서 처리하고 다운로드 파일도 기기에서 만듭니다.
