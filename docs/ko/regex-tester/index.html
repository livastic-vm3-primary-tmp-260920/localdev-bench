실제 비밀번호·JWT 액세스 토큰·고객 개인정보는 붙여 넣지 마세요.

가상 예제로 직접 사용해 보세요

패턴·로그 추출

파일 업로드·쿠키·분석 추적·외부 스크립트 없음. 입력은 브라우저 메모리에서만 처리합니다.

결과

준비됐습니다. 테스트 데이터를 입력하세요.


  

 

 

  
어떤 문제를 해결하나요?
정규식은 일부 행만 매칭되거나 캡처 그룹이 빠질 수 있고, 지나치게 복잡하면 화면을 멈추게 할 수 있습니다. 매치별 시작·끝 위치와 번호·이름 캡처 그룹, 원본을 변경하지 않는 치환 미리보기를 제공합니다.

  
사용 방법
슬래시 없이 JavaScript 패턴을 입력하고 지원하는 플래그를 고른 뒤 가상의 테스트 문장을 붙여 넣으세요. 결과에서 일치 위치와 하이라이트를 확인합니다. Python·PCRE 문법과 완전히 같지는 않습니다.

  
지원 범위와 주의사항
복잡한 정규식은 별도 작업자에서 제한 시간으로 실행합니다. 최대 100개 매치, 32,000자 샘플을 지원합니다. 한 샘플에서 성공했다고 모든 실제 입력에 안전한 패턴이라는 보장은 없습니다.

 

 
자주 묻는 질문
Python 정규식 문법도 되나요?
아니요. 브라우저의 JavaScript RegExp 엔진을 사용하며 Python의 이름 있는 그룹 문법이나 지원 기능이 다를 수 있습니다.
무한 반복되는 정규식은 어떻게 되나요?
별도 작업자를 제한 시간 이후 종료합니다. 화면 멈춤 위험을 줄이지만 정규식 전체 보안 검증 기능은 아닙니다.
입력한 텍스트가 자동으로 바뀌나요?
아니요. 치환은 결과 창에만 표시합니다. 원본 테스트 문장은 직접 지울 때까지 유지됩니다.
