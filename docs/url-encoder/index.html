What problem does this solve?
A space, percent sign or double-encoded query value can silently break links and webhook parameters. This tool supports component encoding, percent/plus decoding and readable query parameter inspection with duplicate keys preserved.

  
How to use it
For a single query value choose Encode; for a percent-encoded value choose Decode. Inspect takes a complete http(s) URL and splits protocol, hostname, path, fragment and every query key/value without contacting the destination.

  
Scope and limitations
URLs are treated as text. Inspection is never a network test of the destination, redirect or tracking endpoint. A copied URL may still contain personal information or tokens; avoid sharing such links.

 

 
Common questions
What is the difference between encodeURI and encodeURIComponent?
Component encoding escapes reserved separators such as ampersand, equals and question mark, making it suitable for an individual query value.
Does the inspector click or fetch the URL?
No. It parses the URL locally without navigating to it or resolving its host.
Can I inspect duplicate UTM or query keys?
Yes. The query list retains duplicate keys in order so you can spot accidental repeated parameters.
