What problem does this solve?
A file can contain individually valid JSON objects separated by newlines but fail as one JSON document. JSONL requires one parseable JSON value per nonempty line; a stray comma or newline inside a record can break a batch. This tool identifies the exact lines and exports a standard JSON array when all lines pass.

  
How to use it
Paste a few fictional NDJSON lines, then click Validate. Inspect line-specific errors, record counts and object/array/value types. Export JSON only when validation succeeds. For CSV/JSON table conversion, the separate free LocalCSV Lab tools may be more suitable.

  
Scope and limitations
This is a syntactic parser only; it does not verify OpenAI Batch schema, n8n node types or business-level data correctness. It doesn't submit your rows to any API. Avoid huge or sensitive production dumps in any third-party page.

 

 
Common questions
How is JSONL different from a JSON array?
JSONL has one complete JSON value per line. A JSON array encloses all records in [ ] with commas; this validator can produce an array only if every nonblank line parses.
Can I use this as an OpenAI Batch API validator?
It checks JSON syntax by line only, not request shape, model access or API eligibility.
Will it upload the NDJSON file?
No. Pasted text is parsed and converted on your device, and the download is generated locally.
