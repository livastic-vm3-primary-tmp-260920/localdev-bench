What problem does this solve?
Classic btoa/atob can corrupt or reject Unicode strings because Base64 operates on bytes, not text characters. This tool explicitly uses UTF-8 for input and output, rejects malformed padding and explains binary data that isn't valid UTF-8.

  
How to use it
Choose Encode or Decode, paste disposable text, then click Run. The result can be copied into your test request. Base64 is an encoding, not encryption or confidentiality protection.

  
Scope and limitations
Text mode only. This UI does not decode arbitrary binary files, PEM certificates or data URLs. It never submits input or output to any API, but you should still avoid placing confidential secrets in shareable URLs.

 

 
Common questions
Will Korean characters work?
Yes. The encoder converts Unicode text to UTF-8 bytes before Base64. The decoder requires valid UTF-8 output.
Is Base64 a way to secure a password?
No. It only changes representation. Anyone can decode it; use proper encryption and credential handling.
Can I decode images or zip files?
Not in this text-only tool. Binary files may not be UTF-8 and are intentionally rejected.
